# Royal Rescue 3D – Android 1.1.0

Download: [RoyalRescue3D-debug.apk](RoyalRescue3D-debug.apk)

Android ARM64, mindestens Android 7.0 / API 24, Vulkan-Mobile-Renderer, Portrait. Offline-Spiel ohne Internetberechtigung. Die APK ist mit einem Debug-Schlüssel signiert.

Diese Version enthält die neuen 3D-Modelle sowie eine deterministische Granulatsimulation: Kombinationen öffnen konkrete Auflagen, Schutt fällt nach unten und rutscht seitlich weiter. Der König flieht erst, wenn der Druck aus seiner Passage verschwunden ist. Alle 100 Seed-Level wurden mit derselben Spiellogik und Simulation gelöst; 87.399 Prüfungen bestanden, längste Lösung 16 von 22 Zügen.

APK-Struktur, Signatur, ARM64 und 16-KB-Alignment sind geprüft. Ein vollständiger Spielablauf wurde mit simulierten Touch-Ereignissen im Vulkan-Mobile-Renderer am Desktop geprüft. **Installation und Spielstart auf Android sind mangels Gerät/Emulator nicht getestet.**
